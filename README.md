# Muhammad Zulqarnain — Lead Generation & SDR Specialist Portfolio

A modern, responsive, high-converting B2B portfolio website built specifically for **Muhammad Zulqarnain**, Lead Generation & SDR Specialist (3+ Years of Experience).

## 🚀 Key Features

- **No Framework Dependencies**: Built with pure semantic HTML5, modern CSS3 (Flexbox & Grid with CSS Variables), and vanilla ES6+ JavaScript.
- **B2B Executive Aesthetics**: Clean Deep Navy & Professional Blue color hierarchy tailored for international B2B clients.
- **No Direct Form Distraction**: Direct communication CTAs optimized for conversion via direct Email (`mailto:`), WhatsApp, and LinkedIn.
- **Interactive Portfolio Filter**: Filter project case studies seamlessly using Javascript without page reloads.
- **100% Responsive**: Built mobile-first for Desktop, Laptop, Tablet, and Mobile devices.
- **SEO & Social Ready**: Features complete meta descriptions, keywords, and OpenGraph tags.
- **Graceful Asset Fallbacks**: Built-in CSS visual frames render seamlessly even before custom portfolio and profile images are uploaded.

## 📁 Image Asset Instructions

Place your project and profile photos in the `/images` folder with the following names:

1. **Profile Picture**: `images/profile.jpg`
2. **Medical Prospecting Case Study**: `images/project-medical.jpg`
3. **Consulting Outreach Case Study**: `images/project-consulting.jpg`
4. **B2B Buyer Research Case Study**: `images/project-b2b.jpg`
5. **OEM Manufacturing Case Study**: `images/project-oem.jpg`

*Note: If image files are not found, the website will automatically display professional dark blue visual placeholder badges with full textual descriptions.*

---

## ✏️ How to Customise Contact Details

Open `index.html` and replace the following placeholder strings:

1. Replace `YOUR_EMAIL@example.com` with your real business email.
2. Replace `YOUR_WHATSAPP_NUMBER` with your WhatsApp phone number (include country code without `+`, e.g., `923001234567`).
3. Replace `YOUR_LINKEDIN_URL` with your LinkedIn username or full profile URL path.

## 🛠️ How to Test / Run

1. Clone or download this project directory.
2. Double-click or open `index.html` directly in any web browser (Chrome, Firefox, Safari, Edge).
3. No local server, backend, or build command (`npm run build`) required!
